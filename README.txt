2. HOW TO USE
--------------------------------------------------

1. Extract the ZIP file after downloading.

2. Open the project folder.

3. Open "index.html" in a modern web browser.

4. Replace the demo information with your own
   school's information.

5. Save your changes.

6. Refresh the browser to see your changes.

No installation or special software is required
to view the basic website.

7. CONTACT FORM
--------------------------------------------------

The contact form is connected to Formspree.

When a visitor submits the form, the information
is sent through the configured Formspree endpoint.

The form collects:

- Full Name
- Email Address
- Subject
- Message

IMPORTANT:

The Formspree endpoint included in this template
is configured for the template demonstration.

Before using this website for a different school,
create your own Formspree form and replace the
Formspree endpoint in "index.html".

Look for:

action="https://formspree.io/f/..."

Replace the existing endpoint with your own
Formspree endpoint.

This ensures that contact messages are delivered
to the website owner's email address.
